# Models Section Overview

This section contains the saved model files generated from the final LightGBM pipeline. These files are used by the Streamlit dashboard for deployment.

## Contents
- `final_model.pkl` – Trained LightGBM model for vehicle price prediction  
- `final_scaler.pkl` – Preprocessing scaler for input features  

## Notes
These saved models were produced during the modeling process documented in the [`/modeling`](../modeling) section and are required for running the [`/estimator_dashboard`](../estimator_dashboard) app.
